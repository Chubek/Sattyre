Registry Server and Client Flow

Stage 6 local-first registry and HTTP endpoints.

Scope

This chapter covers RegistryServer and RegistryClient APIs and staged HTTP features. Start with local, scriptable behavior before distributed deployment polish. RegistryStatus values should describe not-found and I/O failures clearly.

sattyre::RegistryClient client;

Client operations

deploy_http uploads a bundle to registry. download_http pulls package bundle by name. list_http fetches package list for inspection and automation.

sattyre-registry publish ./demo.satpkg --url http://127.0.0.1:8080
