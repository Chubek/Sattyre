Stage 1 baseline:\+ CMake authority, options, and project structure.\hypertarget{chapter1_autotoc_md2}{}\doxysubsubsection{\texorpdfstring{Why this chapter}{Why this chapter}}\label{chapter1_autotoc_md2}
Sattyre starts with a build system that fails clearly and enables optional subsystems deliberately. This chapter focuses on CMake options and directory ownership so contributors do not blur boundaries. The goal is a stable developer baseline before touching parser, solver, plugin, or packaging internals.
